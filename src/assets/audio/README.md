# Real Moose Call Audio Files

This directory should contain the real moose call audio files for each species.

## Required Files:
1. `alaska-yukon-moose-call.mp3` - Alaska-Yukon Moose species call
2. `northwestern-moose-call.mp3` - Northwestern Moose species call
3. `eastern-moose-call.mp3` - Eastern Moose species call
4. `shiras-moose-call.mp3` - Shiras Moose species call

## How to Add:
1. Download or record real moose call audio files for each species
2. Convert them to MP3 format
3. Place them in this directory with the exact filenames above
4. The app will automatically load and play them through the AudioService

## Notes:
- Audio files should be in MP3 format for best compatibility
- Keep file sizes reasonable (< 5MB) for app performance
- Professional moose call recordings are recommended for authentic practice experience

## References:
- Search for "moose call audio" or "moose bugle recording" online
- YouTube has authentic moose call videos with downloadable audio
- Professional hunting resource sites often have audio libraries
